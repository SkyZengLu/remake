# 游戏介绍与玩法

## 这是什么游戏

《人生重开模拟器》是一款**文字模拟养成游戏**：你投胎成新的人，用随机抽到的天赋和有限的
属性点开局，然后看着这个人从出生到死亡的一年一年过完。人生中会遇到什么事件、能活多久，
都取决于你的初始属性、天赋和一点运气。

死掉不是结束 —— 点「立即重开」就能再来一世。**重开次数越多，抽到高稀有度天赋的概率越高**，
所以每一世都在为下一世积累运气。

## 游戏模式

| 模式 | 玩法 |
| --- | --- |
| **经典模式** | 随机抽 10 个天赋，从中选 3 个，再自由分配属性点 |
| **名人模式** | 前世是古代名人，重开到了现代；开局需要抽角色，且重开次数有限制 |
| **我的命运我做主！** | 列出**全部**天赋，最多可选 10 个，可一键清空 |

## 一局的完整流程

```
选模式 → 抽天赋 → 选天赋 → 分配属性点 → 一年一年过完人生 → 结算评价 → 解锁成就
```

**第一步：抽天赋**

每次抽 10 个候选。天赋分 5 档，用颜色区分，越稀有越强：

| 档次 | 基础概率 | 权重 |
| --- | --- | --- |
| 白色 | 约 88.85% | 889 |
| 蓝色 | 约 9.99% | 100 |
| 紫色 | 约 1.00% | 10 |
| 金色（橙色） | 约 0.10% | 1 |
| **彩色** | 约 0.05% | 0.5 |

> 彩色档是本修改版新增的最高稀有度，出货率为**金色的一半**；
> 金色与彩色会随成就数量同步加成，两者始终保持「彩色 = 金色的一半」这一关系。

**第二步：选天赋**

经典模式下从 10 个里选 3 个。

**第三步：分配属性点**

基础 **20 点**，分配给 4 项属性，**单项最多 10 点**（快乐不占用这 20 点，默认从 5 开始）：

| 属性 | 影响 |
| --- | --- |
| **颜值** | 影响恋爱、社交类事件 |
| **智力** | 影响学业、职业、修炼类事件；高智力更容易走修仙路线 |
| **体质** | 影响健康和寿命，体质太低容易早夭 |
| **家境** | 影响财富、生活质量类事件 |
| **快乐** | 独立的幸福感数值，部分结局与它有关 |

有些天赋会额外赠送属性点，例如橙色天赋【禄】直接 **+2000 点**。

**第四步：过完这一生**

游戏按「岁」推进，每一年随机触发事件，属性随之增减。寿命耗尽（或 500 岁上限）后人生结束，
系统给出总评——从「地狱」到「传说」等档位。

**第五步：重开**

人生结束后进入结算，解锁成就、累积重开次数，然后开始下一世。

## 1.0 更新内容

### 界面

- 使用 **Material 3** 风格重新设计：顶部应用栏、圆角卡片、填充按钮、M3 色板与深浅色主题。
- 彩色天赋以**彩虹渐变**呈现（橙 → 玫红 → 紫 → 青）。

### 天赋

| 天赋 | 稀有度 | 描述 | 效果 |
| --- | --- | --- | --- |
| **【禄】** | 橙色 | 【Sky增禄】。 | 初始可用属性点 **+2000**，快乐 **+100** |
| **【气运之子】** | 彩色 | 遇到增加属性的事件概率大幅提升 | 增加属性的事件权重 **×3** |
| **【先天道体】** | 彩色 | 悟出大道的概率大幅提升 | 悟道事件权重 **×3** |

### 修仙内容调整

**悟出大道的概率改为全局随智力变化：**

| 智力 | 悟出大道的概率 |
| --- | --- |
| 0 | 1% |
| 500 | 2% |
| 1000 | 3% + 原有 1% = **4%** |
| ≥ 1000 | 4%（封顶） |

持有【先天道体】时，在此基础之上再 ×3。

### 存档与多端

- **存档导出与导入**：顶部应用栏的「导出 / 导入」两个按钮。
  - 手机端：导出生成 JSON 存档并调起系统分享；导入选择文件后恢复。
  - 桌面端：调用 Windows 原生文件对话框。
- **Android 离线版 APK**：包名 `com.skyzenglu.liferestart`，应用名「人生重开」，可断网运行。
- **Windows 便携版 exe**：免安装、双击即用，同样离线；日志每次启动自动清空重建。

## 1.0 修复记录

| 问题 | 修复 |
| --- | --- |
| 「运用时间大道回到了100年前」「转世重生」等事件**只改文案、不改年龄** | 上游的事件触发逻辑漏了 `AGE` 字段，已补上；涉及 `11468`（-5）、`11469`（-50）、`20390`（-100）、`20409`（-500）四个事件，并补了 4 个单元测试 |
| 200 岁之后「灵气浓郁 / 捡到异果」不再出现 | 上游数据里这两个事件只配到 199 岁，已补回 **200~499 岁** |
| 500 岁终局年龄被上面的补丁污染，渡劫被异果挤掉 | `age=500` 恢复原样，只保留「寿元终 / 开始渡劫」两个候选项 |

## 上手建议

- **先随便玩几世**：天赋和属性都靠运气，前几局主要是熟悉事件类型和积累重开次数
- **前期优先体质和智力**：体质太低会早早死掉，智力影响后期路线的开启条件
- **重开次数是关键资源**：想抽到彩色天赋，最有效的办法就是多玩
- **想走修仙飞升线**：智力要堆到 **500 以上**才能开启「渡劫期」，否则会卡在元婴九层
- **彩色天赋很强，但概率极低**：金色的一半都不到，别指望每局都能抽到
